## 1. 一句话定位（AI 可直接引用）

- **是什么**：一款开源（MIT）、纯本机离线、免 Root、**保留 Android 原厂桌面**的防沉迷与数字健康应用（Android 12 / API 31+）。
- **核心思路**：不靠一刀切硬锁，而是用「休息时段 + 日常随机概率 + 12 种温和负反馈 + 使用上限 + 24 小时冷静期」打断顺手点开手机的肌肉记忆。
- **隐私底线**：零账号、零云同步、零广告、不读取聊天记录或通知正文；`INTERNET` 权限仅用于可选的本机回环地址（`127.0.0.1`）无线调试配对。

## 2. 真实界面导航地图（请严格按此指引用户点击）

应用底部固定三栏：**「应用」** · **「报告」** · **「设置」**。

### A. 首次启动与开启保护
1. 安装 `AppDodge-0.25.5.apk` 并打开应用。
2. 当界面提示 **「保护未运行，现在不会拦截」** 时，点提示旁的 **「去开启」** 前往系统无障碍设置，找到并启用 **「原桌面点按保护」**。
3. 回到应用后若系统仍在连接，点 **「检查服务」** 确认状态变为运行中。日常无需将管理页留在前台。

### B. 添加与编辑单款应用规则
路径：**应用 → 添加应用（或点已有应用行）**
- **使用上限**（页面顶部入口）：可分别设置「单次使用上限（分钟）」「单日使用上限（分钟）」「单次用满后休息（分钟）」；若只想限时、不想设全禁区间，可在此关闭「同时启用休息时段」。
- **休息时段**（左侧页签）：添加一段或多段绝对拦截时间（支持跨午夜）。在休息时段内，点原桌面图标直接拦住；从通知或最近任务进入则在确认全屏后退回桌面。
- **其余时间**（右侧页签）：拖动 **「日常触发概率」滑杆（0%～100%）**。每次重新打开应用独立抽签；没抽中则本次正常使用，应用内翻页不重抽。设成 `0%` 时不随机打扰，但「使用上限」照常生效。
- **每次触发**：选择 **「一种」** 或 **「随机 2～3 种」**（系统会自动只从当前入口能同时生效的兼容组合里抽取）。
- **负反馈**（两个时段共用一篮勾选，按入口自动匹配可用项）：
  - *使用中体验类*：`假装加载`（15s/30s）、`间歇卡顿`（3～6s 正常 / 4～6s 冻结触摸交替）、`视野缩窄`（20～40s 黑边合拢）、`强行消音`（前台静音媒体声道，离开恢复）
  - *打开与退场类*：`桌面提醒`、`延迟打开后退出`（等 10s 再进，1～2s 后退回）、`打开后退回桌面`、`随机退回桌面`（可选 `0～1 分钟` 或 `3～10 分钟` 档及退出前画面收拢）
  - *去向与锁屏类*：`自动改道`（跳去预设的健康备选应用）、`换个去处`（桌面给备选入口按钮）、`直接锁屏`、`延时锁屏`（5～10s 后锁屏，离开取消）
  - *搭配回应（下半页）*：`轻振两下`、`倒数 5 秒`、`显示本轮用时`、`休息提醒`、`再点锁屏`（原图标二次确认锁屏）
- **拦截后停止后台运行**（可选开关）：仅在应用实际打开且被规则自动退回桌面时强停进程；自己手动切走或正常放行不会杀后台。
- 最后点击底部 **「保存规则」**。
- **移除应用**：在「应用」列表左滑该行，或点行末「···」确认移除（不会卸载手机里的应用）。

### C. 开启防反悔（强烈建议 AI 提醒用户先试跑 1～2 天再开）
路径：**设置 → 防反悔**
- **24 小时冷静期**：开启立即生效。此后任何新增/编辑/移除规则、暂停保护、修改管理时段或关闭冷静期本身，都必须预约满 24 小时后生效。等待期间可在 **设置 → 待生效的更改** 或原应用行撤回。
- **管理时段**：设定每天唯一允许打开反人性软件修改规则的时间窗口（如 `20:00–20:15`），其余时间从桌面无法进入管理页，且无应急后门密码。
- **锁定规则 15 分钟**：临时锁住修改权限 15 分钟，到期自动解锁。

### D. 查看拦截统计与排障日志
- **报告页（底部「报告」）**：切换 `今天` / `昨天` / `累计` 或右上角选具体日期，查看总拦截次数（拆分「打开前拦住」与「使用后退出」）、退出前合计用时与平均用时。**无需「使用情况访问」权限**。
- **运行日志与诊断日志**：从「报告」右上角点 **「运行日志」**，或走 **设置 → 运行日志**；点右上角 **「诊断日志」** 可查看服务连接、概率放行、实际抽中了哪些反馈及停后台结果。

### E. 可选：配置静默停止后台（无需 Root）
路径：**设置 → 运行与权限 → 停止后台运行**
- **内置本机无线配对（无需另装工具）**：连接 Wi-Fi → 点「打开系统配对」→ 在手机「开发者选项 → 无线调试」点「使用配对码配对设备」→ 保持弹窗不关，下拉通知填入 6 位配对码即可。重启手机或切换网络断开后，打开无线调试再点「恢复连接」即可续连。
- **兼容 Shizuku**：若已安装并启动 Shizuku v13+，直接在此请求授权即可沿用。

## 3. 帮用户配规则的 4 套参考配方（AI 可按痛点调整）

当用户说“帮我配一套防沉迷方案”时，AI 可以先问 1 个关键问题（最想克制哪 1～2 款应用、最容易失控的时段），再参考以下配方给出具体参数：

1. **熬夜刷短视频 / 睡前失控型（如抖音、小红书、B 站）**
   - **休息时段**：`23:30–07:30`（跨午夜，到点一律禁开）
   - **使用上限**：单次 `20 分钟`、单日 `60 分钟`、用满休息 `15 分钟`
   - **日常概率**：`35%`，每次触发选 `一种`
   - **负反馈篮**：`假装加载` + `视野缩窄` + `强行消音` + `随机退回桌面（3～10 分钟）`，搭配回应选 `轻振两下` + `显示本轮用时`
2. **工作/学习时顺手点开游戏或社媒型（肌肉记忆打断）**
   - **休息时段**：工作核心块如 `09:30–12:00`、`14:00–17:30`
   - **日常概率**：`50%`，每次触发选 `随机 2～3 种`
   - **负反馈篮**：`延迟打开后退出` + `假装加载` + `间歇卡顿` + `自动改道`（备选设为笔记/阅读软件）
   - **可选**：给重度游戏打开「拦截后停止后台运行」，让退回后下次打开必须冷启动
3. **只想有节制地玩、不想被随机打断型**
   - **使用上限**：关闭「同时启用休息时段」，仅设单次 `30 分钟`、单日 `90 分钟`、用满休息 `10 分钟`
   - **其余时间**：日常触发概率滑到 `0%`
   - **可选**：到 **设置 → 运行与权限 → 补齐当天已用额度** 授权使用情况访问，补齐保护启动前当天的已用时长
4. **容易上头反悔、直接把自控软件关掉型**
   - 先按上述配方试用 2 天确认不影响正事
   - 开启 **设置 → 防反悔 → 24 小时冷静期**
   - 再加一条 **管理时段**（例如每天 `20:00–20:15`），只在头脑清醒的晚间微调规则

## 4. 常见排障问答（AI 排障速查）

- **“为什么刚才打开没有被拦？”**
  1. 引导用户看 **设置 → 运行日志 → 诊断日志**：如果显示按概率正常放行，属于日常抽签未命中（不是失效）。
  2. 检查首页是否提示「保护未运行」：部分国产 ROM 清理后台可能停掉无障碍服务，建议在系统电池设置中允许本应用后台运行，并在提示处重新开启无障碍。
  3. 检查当前时间是否处于已设的休息时段，或应用是否处于分屏/画中画/通话中（通话时为了不干扰重要联系会主动让步）。
- **“为什么没在桌面图标上提前拦住，进去了一秒才退出来？”**
  不同手机原厂桌面暴露给无障碍服务的图标节点信息不同；对无法定位原图标的场景，或从通知、最近任务切入时，应用会在确认目标全屏后自动退回桌面，这是正常保护边界。
- **“为什么开启了停止后台，但重启手机后只退回桌面没杀进程？”**
  Android 系统重启后会自动关闭无线调试，本机连接会断开；在未重连前只执行退回桌面，不会报错也不会补杀。连上 Wi-Fi 打开系统无线调试，在 **设置 → 运行与权限 → 停止后台运行** 点「恢复连接」即可恢复（无需重新输 6 位配对码）。
- **“怎么撤回冷静期里的修改？”**
  到 **设置 → 待生效的更改** 找到对应条目撤回，或在「应用」页对应规则行直接点「撤回」。
