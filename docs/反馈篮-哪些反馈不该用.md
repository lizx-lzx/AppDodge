# 反馈篮：打断顺手点开，不把伤害当作强度

这份说明记录 AppDodge（反人性软件）选择负反馈时的设计边界：用可预料、可退出的温和摩擦打断条件反射，而不是靠恐吓、羞辱或生理刺激来制造强度。

**不放进随机池的三类后果：**

- 强声、反复强光闪烁有生理风险。足够强的声音可能损伤听力；闪烁对部分人可诱发偏头痛或癫痫发作。[WHO 安全聆听](https://www.who.int/news-room/questions-and-answers/item/deafness-and-hearing-loss-safe-listening)；[W3C 对闪烁的说明](https://www.w3.org/WAI/WCAG22/Understanding/three-flashes.html)。
- 公开羞辱与曝光不是中性的提醒。81 人随机分组实验中，同样做演讲和心算，被他人评价的一组羞耻感上升更多。研究测的是当场的反应，不是手机自控的长期效果。不嘲讽用户，也不把点按情况私发给他人。[原始实验，2004](https://pubmed.ncbi.nlm.nih.gov/15564358/)。
- 牵连目标应用以外的后果。随机整机锁屏、真实扣款、删资料，作用对象不再是这一刻想打开的应用，还可能影响当下的导航、联系或工作。产品建议：强度可预料，后果只发生在事先选定的范围；单独启用的二次锁屏，也须先说明后果再由同一次体验中的下一次有意点按确认。

**值得比较的体验：** 目标应用的时段规则保持不变，用户可立刻去做别的事；在此基础上，比较固定的安静反馈与同强度反馈轮换，观察被拦后一分钟内重试同一应用的比例，以及是否更常关闭保护。倒数只表示提示还剩多久，不代表应用即将放行。避免必须打字、长按或连续点按才能离开。

**实据的边界：** 2023 年 one sec 研究的现场主分析只纳入坚持使用六周的 280 人。他们一共发起的打开尝试中，36% 在提示后被本人放弃；这不是对照组差值。另有 500 人的随机视频实验：播放前能直接跳过的效果优于只做短暂等待，单独出示反思文字没有明显效果。未比较 AppDodge 的固定和随机反馈，也未验证长期停用后的习惯。[论文全文，PNAS](https://doi.org/10.1073/pnas.2213114120)。
