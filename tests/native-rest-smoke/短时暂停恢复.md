# 严格模式真机实验：先确保计算器能恢复

这是测试端工具，不包含在 APK 里，也不会把暂停权限授予 AppDodge。仅在机主明确同意、iQOO 12 空闲、USB 调试正常且未在通话时使用。它只对机主（用户 0）的原厂计算器操作；初始状态无法读取或已经暂停则拒绝，不替其他管理者解除限制。应用未放在原生主屏或不能独立恢复时不要执行。

从项目目录出发，先把 `S` 设为当次确认的序列号。每次测试生成独立目录。先检查 `nohup` 和 `setsid` 是否存在，不在真机替换系统工具。

```sh
adb -s "$S" shell 'ls -l /system/bin/nohup /system/bin/setsid'
R=$(adb -s "$S" shell 'mktemp -d /data/local/tmp/appdodge-watch.XXXXXX' | tr -d '\r')
adb -s "$S" push tests/native-rest-smoke/short-suspension.sh "$R/guard.sh"
adb -s "$S" shell "/system/bin/nohup /system/bin/setsid /system/bin/sh '$R/guard.sh' --authorized-iqoo-calculator 60 </dev/null >'$R/receipt' 2>&1 & echo detached"
adb -s "$S" shell "cat '$R/receipt'"
```

只有记录里出现 `ACTIVE suspended=true` 才算暂停成功。不要重复启动 worker。60 秒计时从暂停前开始；不要把剩余时间很短时的“打开了”记为漏拦。最多允许 90 秒。测试结束可立即请求同一个 worker 恢复：

```sh
adb -s "$S" shell "touch '$R/stop'"
# 等 receipt 有 RESTORED，且实际 User 0 的包状态是 suspended=false。
adb -s "$S" shell "cat '$R/receipt'; dumpsys package com.android.bbkcalculator | grep 'User 0:.*suspended='"
# 仅在上述两项均确认后，清除测试文件。
adb -s "$S" shell "rm -f '$R/guard.sh' '$R/receipt' '$R/stop'; rmdir '$R'"
```

2026-11-24 在独立 Android 14 模拟器用 shell 身份、只对 `dev.local.dodgelab` 验证：终止发起命令的 Mac 端 adb 进程后，手机端仍显示已暂停，8 秒测试到期后恢复；另一轮写入 stop 后提前恢复；若原来已暂停，则拒绝操作，原状态不变。没有用真机掉线代替模拟器试验。

断开 Mac 不会按照脚本逻辑取消设备端 worker。关机、设备重启、进程被系统杀死等情况可能让它无法恢复；深睡也可能推迟恢复。在确实由本轮测试暂停而未收到恢复回执时，应重新连接，使用 `adb -s "$S" shell cmd package unsuspend --user 0 com.android.bbkcalculator` 后重新检查状态、确认计算器正常打开。shell 发起的解除命令只移除其自身归属的暂停；若仍有其他管理者的暂停，不将其移除。
